# 집에서 Codex에 보낼 첫 메시지

아래 내용을 새 Codex 작업창에 그대로 보냅니다.

```text
bid2 프로젝트를 이어서 작업하려고 합니다. 현재 열어둔 프로젝트 루트를 기준으로
다음 문서를 순서대로 읽어 주세요.

1. docs/INDEX.md
2. docs/SETUP_NEW_PC.md
3. docs/HANDOFF.md
4. docs/MAPPING.md
5. docs/TODO.md
6. docs/PROPOSAL_REFERENCE_GUIDE.md

그다음 git status와 최근 커밋 3개를 확인하고, 현재 설치된 Python/Node 환경,
server/.env 존재 여부, migration 상태를 확인해 주세요.

코드를 바로 수정하지 말고 먼저 다음 내용을 간단히 알려 주세요.
- 현재 프로젝트가 어디까지 완성됐는지
- Git에 포함되지 않아 새 컴퓨터에서 다시 준비해야 하는 데이터
- 현재 서버와 웹을 실행할 수 있는 상태인지
- TODO에서 다음으로 진행할 한 가지 작업

나는 학습하면서 진행 중이므로 수정할 파일 경로, 수정 이유, 전체 흐름을 간단한
CLI 그림으로 설명해 주세요. 한 번에 불필요하게 많은 기능을 추가하지 마세요.
```

이전 대화 기록을 새 Codex가 자동으로 기억한다고 가정하지 않습니다. 현재 상태는
Git으로 받은 코드와 `docs/HANDOFF.md`를 기준으로 판단합니다.
