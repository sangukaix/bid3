- 회사 홈페이지를 같은 도메인 안에서 최대 8페이지 수집하고 `CompanyWebsitePage`와 `CompanyKnowledgeItem`에 저장합니다.

- 프로젝트 삭제는 휴지통 이동으로 변경했으며 복원 시 프로젝트 목록의 마지막에 배치됩니다.
- 휴지통 영구 삭제 시에만 제안서·채팅·분석·정량자료·유사 제안서를 실제 삭제합니다.

```text
전체 첨부문서 추출·색인

  -> 요구사항 목록 저장
  -> 관련 상세 원문 검색
  -> 전략·PPTX 작성
  -> 요구사항 누락·슬라이드 품질 검수
```

## 기술 구성

- 프론트엔드: Next.js 16 + React 19 + TypeScript
- 백엔드: Django 5.2 + Django REST Framework
- 개발 DB: SQLite, 운영 전 MySQL 또는 PostgreSQL 검토
- 공고 수집: 나라장터 Open API
- AI: OpenAI + LangChain + Chroma
- 제안서 결과: PPTX, PDF 미리보기

## 주요 AI·RAG 설정

- 공고 채팅: `gpt-4o-mini`, 답변 800 tokens, 원문 최대 20,000자
- 공고 Chunk: 500자, overlap 100자, `text-embedding-3-small`
- 검색: 후보 최대 30개, 관련도 0.2 이상, 결과가 부족하면 상위 5개 보장
- 전체 요구사항: `gpt-5.6-terra`, 묶음 4,000자, 묶음당 출력 5,000 tokens
- 정성 제안서: `gpt-5.6-sol`, 공고 원문 최대 160,000자, 전략 출력 12,000 tokens
- 정량평가: `gpt-5.6-sol`, 원문 최대 70,000자, 출력 12,000 tokens
- 회사 지식: `gpt-4o-mini`, 전체 160,000자, Chunk 1,800자/overlap 200자
