# 관리자 AI 유지보수

화면: /maintenance. 기존 admin 계정 또는 is_staff 관리자만 설정을 조회·저장할 수 있다. 일반 사용자와 비로그인 접근은 서버 API에서 차단한다. 로그인한 관리자는 오른쪽 아래 작은 점으로 이동한다. 비밀번호는 기존 계정의 비밀번호를 사용한다.

## 독립 구조

- server/maintenance/: 설정 저장, 검증, 관리자 API
- web/features/maintenance/: 관리자 화면과 작은 진입 버튼
- web/app/maintenance/page.tsx: 페이지 진입점
- .local/ai-routing.json: 이 PC의 비공개 실행 설정. Git 제외.
- .local/ai-routing-backup-*.json: 이전 설정 백업

화면은 작업별 제공자와 모델 태그를 저장한다. Qwen과 Gemma는 같은 Ollama 제공자에서 모델 이름으로 선택한다. 모델 설치는 별도로 해야 하며 연결 확인 버튼은 Ollama 모델 목록만 조회한다. 모델 목록이 보인다고 해당 작업 품질이나 모든 기능 호환성이 보장되지는 않는다.

로컬 전용 모드에서는 모든 작업이 Ollama여야 한다. OpenAI SDK 호출을 차단하며 자동 폴백은 없다. 작업별 선택 모드에서는 지정한 작업만 OpenAI로 보낼 수 있다. 키는 기존 서버 환경에서 읽으며 브라우저에 반환하거나 입력받지 않는다. OpenAI 잔액은 검사하지 않는다.

작업: 채팅, 공고 분석, 회사 지식, 요구사항, 제안서, 정량서식, 회사 근거 검토, 사업자등록증 텍스트/PDF, 이미지 추출. 로컬 이미지 경로에서는 텍스트 PDF를 별도 텍스트 역할로 처리하며, 이미지 제공자가 OpenAI이면 PDF도 그 경로에서 처리한다. Gemma/Qwen 모델을 이미지 역할로 선택하려면 해당 태그가 이미지 입력을 지원해야 한다.

관리자 설정이 있으면 키워드 검색·공개 웹 조회를 유지하여 숨은 임베딩/검색 비용을 방지한다. 저장된 설정은 .env보다 우선한다. 설정 파일이 없으면 기존 .env 동작을 유지한다. 잘못된 설정 파일은 실행 오류로 처리하며 클라우드로 자동 우회하지 않는다.

저장은 원자적 파일 교체와 이전 값 백업을 사용한다. 새 모델 생성 호출부터 적용되므로 생성 작업이 진행 중일 때는 설정을 바꾸지 않는 것이 좋다. 현재는 한 로컬 서버 운영을 기준으로 하며 여러 관리자의 동시 저장은 마지막 저장값이 적용된다. 관리자 설정은 PC별이므로 학원 PC의 모델 선택은 자동으로 바뀌지 않는다.

## 확인한 범위

전체 자동 테스트 171개와 웹 lint/build 통과. 실제 관리자 조회 200, 비로그인 API 401, Ollama 설치 모델 qwen3:14b·gemma4:26b 연결을 확인했다. 테스트 실행은 전용 임시 설정 파일을 사용해 운영 선택을 격리한다.

권한 없는 조회/변경 차단, 로컬 OpenAI 설정 거부, 작업별 즉시 라우팅, 손상 파일 실패 처리, 모델 목록 조회를 자동 테스트한다. 관리자 권한은 진입 버튼 숨김이 아니라 서버 권한 검사로 보호한다. 화면 접속 자체에 설정/비밀키가 포함되지 않으며 인증 후 API로 읽는다.
