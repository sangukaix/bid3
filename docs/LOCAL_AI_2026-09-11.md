# 대형 템플릿 후속 점검 (2026-09-11)

30장 공공입찰 템플릿을 가상 회사·공고로 검사하면서 다음 문제를 수정했다.

- 제목 자리표시자가 없는 템플릿에서 첫 텍스트(로고)를 제목으로 오인했다. 명시적 제목을 우선하고, 없으면 숫자·표를 제외한 큰 텍스트를 선택하도록 수정했다. 실제 30장 템플릿의 페이지별 제목을 확인했다.
- 모델이 동일 텍스트 위치를 여러 번 반환하여 페이지 생성이 실패했다. 위치별 필드를 가진 고정 객체로 바꾸어 허용되지 않은 위치를 거부한다.
- 변경할 내용이 없는 정적 페이지도 실패로 처리했다. 이제 검토 대상으로 유지한다.
- 상자 크기를 넘는 문구가 렌더링에서 건너뛰어졌다. 길이를 사전 검사하고 한 번 축약 재요청하며 계속 초과하면 명시적으로 실패한다.
- 새 작성에서 모델이 비워 둔 자리표시자는 확인 필요로 표시한다. 이 표시는 근거를 채웠다는 의미가 아니며 담당자의 자료 보완이 필요하다.

전체 자동 테스트 161개가 통과했다. 기존 PPTX 처리 엔진의 수정이며 템플릿 디자인은 변경하지 않았다.

## 실모델 검사 범위

이전 실모델 검사는 24페이지까지 기록되었으며, 정적 페이지를 실패 처리하는 문제 등이 관찰됐다. 이번에는 실패·길이 초과·미확인 항목과 미실행 페이지를 재검증한다. 검증 파일은 Git에서 제외된 .local/large-deck에 저장한다. 전체 생성과 최종 시각 검수 완료 여부는 후속 결과에 따로 기록한다.

템플릿 원본의 PowerPoint PDF 변환은 성공했다. 생성물의 원문 충실성, 모든 페이지의 배치와 실제 회사 증빙 일치까지 검증됐다는 의미는 아니다. 상위 모델 설치 및 백그라운드 작업 큐 전환은 이번 수정에 포함하지 않는다.

표지 재검증에서 제공 근거에 없는 강사 경력 표현이 관찰됐다. 길이·문법·파일 검증은 사실성을 보증하지 않으며, 실적·경력·증빙 보유 주장에는 별도 원문 대조가 필요하다.

## 최종 실행 결과

재개 후 30장 PPTX 생성과 PowerPoint PDF 변환을 완료했다. 렌더러 텍스트 적용 경고 0건, 빈 페이지 0건, 중복 제목 0건이었다. 별도 PPTX 패키지 검사는 발견 사항 0건으로 통과했고, 30장·16:9 기하 검사는 경고 0건이었다. 자동 테스트 161개가 다시 통과했다.

다만 앱의 종합 품질 판정은 실패였다. 대괄호 표기 43건(실제 미치환 항목과 모델이 작성한 대괄호 문장 혼재), 작은 글씨 337건(기존 템플릿 라벨 포함), 반복 레이아웃 구간 1건이 검출됐다. 대표 페이지 1·25·27을 시각 확인했으며 제목/본문 상자 배치는 유지되지만 25페이지의 본문은 확인 필요만 남아 있고 27페이지에 공고 요구를 회사 경험으로 잘못 표현한 문장이 있었다. 전체 30페이지의 시각·내용 품질이 통과한 것은 아니다.

현재 로컬 생성은 검토용 초안이다. 다음 단계는 역할별 근거 검증과 실제 회사 자료를 사용한 평가이며, 자리표시자를 없애는 것만으로 내용 완성도를 높였다고 보아서는 안 된다. 검증용 가상 제안서는 사용자 업무 데이터에 저장하거나 Git에 업로드하지 않았다.
