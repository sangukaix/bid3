# 회사 주장 근거 검토

로컬 제안서 생성 및 수정 후, 새로 작성한 텍스트에서 실적·경력·자격·인증·보유·매출 등 회사 주장 후보를 찾아 Qwen으로 대조한다.

## 처리와 표시

- 회사 입력 정보와 회사 지식 자료만 사용한다. 공고 요구사항, 생성 전략, 공개 웹 참고는 회사 증빙으로 전달하지 않는다.
- 문장과 관련 있는 회사 자료 조각 최대 3개를 대조한다. 대조용 문맥은 새로 요약하지 않는다.
- 모델이 지지를 판단하더라도 인용이 전달한 회사 원문에 실제 존재하고 미제공·확인 필요 같은 표현이 없어야 source_matched로 기록한다.
- 일부 주장만 확인되거나 인용이 없거나 자동 검토가 실패하면 review_required로 기록한다.
- 근거 부족 항목은 기존 최종 검토 목록에 페이지·텍스트 위치·이유를 표시한다. 생성 문구 자체를 자동 삭제하거나 회사 사실로 확정하지 않는다.
- 생성 결과 JSON의 company_claim_review에 문장·인용·출처 구분·판정 이유를 저장한다. 수정의 검토 결과는 feedback_history 각 항목에 보존한다.

## 실제 검사

가상 회사 입력으로 실제 Qwen 검사를 수행했다. 명시된 강사 3명은 원문과 연결됐고, 제공하지 않은 경력·30일/20명 수행 경험·ISO 9001 인증은 모두 검토 필요로 분류됐다. 검사 자료는 .local에 보관하며 Git에 올리지 않는다.

## 한계

후보 탐지는 한국어 표현 규칙 기반이므로 모든 주장을 찾지는 못한다. 신규/수정 텍스트에 적용하며 변경하지 않은 기존 페이지 전체에 대한 인증은 아니다. 관련 문맥 검색에서 근거가 빠질 수 있고, 동일 모델의 의미 판정에도 오판 가능성이 있다. 회사 지식은 이전 추출 요약을 포함할 수 있다. source_matched는 자료 진위·원본 증빙 유효성·입찰 자격 충족을 보증하지 않는다.

문구당 추가 로컬 추론이 발생해 제안서 생성 시간이 늘어난다. 자료가 없거나 대조에 실패한 경우 생성을 조용히 승인하지 않고 검토 필요로 남긴다. 현재 기능은 검토 지원이며 자동 제출용 사실 검증을 대신하지 않는다.
