## 변경

- 장문을 반복 요약하는 대신, 실제 프롬프트·스키마·출력 예산에 맞춰 페이지별 원문과 요구사항을 선택한다. 출처와 선택/미선택 ID를 남기고 전체 요구사항은 별도로 보존한다.
- 요약·목표·일정·성과 페이지에는 인원·기간·예산 등 명시된 기본 사업조건을 추가 전달한다. 페이지 제목과의 유사도만으로 기본조건이 밀리는 현상을 줄인다.
- 동일한 모델·설정·스키마·실제 입력의 성공 응답은 `media/local_proposal_cache`에서 재사용한다. 브라우저 작업 큐/진행률과는 별개다.
- 상자보다 긴 문구만 후보 3개로 다시 작성한다. 정상 문구는 유지하고, 원문의 잘린 접두 문구·미닫힌 괄호·`확인 필요` 표현 소실을 거부한다. 글자 수에 맞는 후보 중 긴 것을 선택한다. 의미와 모든 조건의 보존을 보증하는 검사는 아니다.
- null뿐 아니라 원래 자리표시자를 그대로 복사한 응답도 미작성으로 보고 해당 칸만 다시 요청한다. 계속 미작성인 경우 `확인 필요`로 표시한다.
- 모델이 추정한 페이지 제한은 원문에 명시된 상한이 확인될 때만 사용한다. 이번 실행에서 근거 없는 10쪽 제한 추정을 적용하지 않았다. 로컬 경로는 템플릿 페이지를 자동 추가·삭제하지 않는다.
- 전체 199개 항목을 작은 묶음으로 실제 작성 문구와 대조한다. 실제 페이지의 연속 인용문과 요구 수치가 맞아야 반영으로 집계한다. 대조 실패도 미검증으로 기록하여 목록에서 없어지지 않게 한다.
- 모델이 페이지 번호를 생략해 0으로 반환하면, 인용문이 실제 작성 페이지의 한 곳에만 정확히 일치할 때 번호를 연결한다. 잘못 명시한 번호나 여러 페이지에 중복된 인용은 이 방식으로 통과시키지 않는다.
