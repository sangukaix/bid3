# 제안서 템플릿

회사가 업로드한 문서는 디자인 원본이 아니라 회사의 실적, 역량과 강점을
찾는 참고자료로 사용합니다. 새 제안서는 기존 5종 또는 자체 제작 라이브러리
30종 중 선택한 양식으로 생성합니다.

- `default.pptx`: 공공기관 제안에 어울리는 안정적인 기본형
- `modern.pptx`: 비대칭 그리드와 청록 포인트를 활용한 현대적 전문형
- `public_standard.pptx`: 요구사항, 평가항목, 수행체계 중심의 공공입찰 실무형
- `evergreen_grid.pptx`: 실행 계획과 운영 체계를 차분하게 보여주는 신뢰형
- `classic_burgundy.pptx`: 교육·컨설팅 제안에 어울리는 절제된 고급형

`proposal_template_layouts.json`은 각 PPTX 슬라이드의 용도와 권장 내용 분량을
정의합니다. AI는 이 정보를 이용해 일정, 조직, 평가 대응, 실적 등 내용에 맞는
슬라이드를 선택합니다.

`library/`에는 6개 용도로 분류한 자체 제작 30종이 있습니다. 각 20쪽이며
네이티브 텍스트와 표를 편집할 수 있습니다. `library/catalog.json`은 목록,
`library/layouts.json`은 페이지별 작성 규칙, `library/previews/`는 원본 해시와
연결된 미리보기입니다. [제작·재생성 방법](../../template_studio/README.md)을
참고하세요.

AI는 선택한 양식의 목표 장수와 공고의 분량 제한을 기준으로 내용을 구성합니다.

`proposal_generation_rules.json`에는 검토한 제안서 448쪽에서 정리한 공통
구조, 업종별 목차와 글자 수 기준을 저장합니다. 원본 참고 제안서는 개인정보와
용량 문제로 프로젝트에 보관하지 않습니다.
